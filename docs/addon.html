Rodrigues Motion Stitching Add-on

Blender add-on for trying Rodrigues-based motion stitching
Download (v0.1.0) Project Page

Overview

This page provides the initial public release of the Blender add-on for trying Rodrigues-based motion stitching. The add-on is distributed as a ZIP file and can be installed from Blender's add-on preferences.

Requirements

  • Blender 4.5 or later is recommended.
  • The input motions should be prepared as Blender actions or NLA strips.
  • This release is intended for trying the motion stitching workflow.

Installation

  1. Download rodrigues-motion-stitching-v0.1.0.zip using the Download button at the top of this page.
  2. Open Blender.
  3. Go to Edit > Preferences > Add-ons.
  4. Click Install... and select the downloaded ZIP file.
  5. Enable the add-on from the add-on list.

Basic Usage

  1. Open a Blender file that contains the motion clips to be stitched.
  2. Select multiple NLA strips in the NLA Editor in the order you want to connect them.
  3. Open the Motion Stitching panel from the sidebar of the 3D Viewport.
  4. For the first trial, keep the default parameters and run Run Quick Stitching.
  5. Play the generated NLA strip or Action to check the stitched result.
