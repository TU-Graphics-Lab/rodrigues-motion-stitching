Rodrigues Motion Stitching Add-on

ロドリゲスベクトル表現に基づくモーション接続を試すためのBlenderアドオン
Download (v0.1.0) Project Page

概要

本ページでは，ロドリゲスベクトル表現に基づくモーション接続を試すための Blenderアドオンの初期公開版を配布しています．アドオンはZIPファイルとして配布され， Blenderのアドオン設定画面からインストールできます．

動作環境

  • Blender 4.5以降を推奨します．
  • 入力モーションは，BlenderのActionまたはNLA stripとして準備してください．
  • 本リリースは，モーション接続ワークフローを試すための初期公開版です．

インストール方法

  1. このページ上部のDownloadボタンから rodrigues-motion-stitching-v0.1.0.zip をダウンロードします．
  2. Blenderを起動します．
  3. Edit > Preferences > Add-ons を開きます．
  4. Install... を押し，ダウンロードしたZIPファイルを選択します．
  5. アドオン一覧からアドオンを有効化します．

注意事項

  • GitHub Releaseページに自動表示される Source code はBlenderアドオン本体ではありません． アドオンを利用する場合は，このページのDownloadボタンからZIPファイルを取得してください．
  • ドキュメントやサンプル資料は，今後の確認後に順次更新予定です．
